# WEATHER FORECAST APPLICATION IN SALESFORCE 
Technologies: Salesforce, Apex, LWC, Open Weather API 
• Integrated Open Weather API with Salesforce to retrieve real-time weather information based on city or state name. 
• Built a user interface using Lightning Web Components (LWC) for user input and data display. 
• Implemented Apex classes to make HTTP callouts to the API. 
• Displayed current weather forecasts including temperature, weather conditions, and city/state details.
